# Device adapter template

Starting geometry for ER80 device adapters.

## Onshape template

[Open the editable template in Onshape](https://cad.onshape.com/documents/fb0dd42ad10a1523afac7c45/w/2e96b723ed7283d5c78a0a61/e/b73b7ce0a00f62bfe81d42b5)

Make a copy of the document, set `rail_span`, then edit the `EDIT_ME` sketch to connect the mounting tabs to your device.

The template provides:

- 80 mm rail spacing
- 20 mm slot spacing
- 5.2 mm mounting holes
- 12 × 12 mm mounting tabs
- calculated inner and outer mounting positions
- adjustable rail span

For devices spanning two or more rails, the recommended convention is:

- left adapter: outer mounting positions
- right adapter: inner mounting positions

This is a recommendation, not a requirement.

## Other CAD software

`device-adapter.dxf` contains the template sketch for use outside Onshape.
