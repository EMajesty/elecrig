# Contributing

Contributions are welcome.

You can help by:

- designing new pedal or device adapters
- creating accessories
- testing existing parts
- improving documentation
- proposing improvements to ER80

For hardware contributions, please include STEP plus printable files where
relevant, and say whether the design has been physically tested.

Start from the templates in [`cad/templates/`](cad/templates/) where possible.
