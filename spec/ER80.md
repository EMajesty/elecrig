# Elecrig Rail 80 (ER80)

ER80 is the basic rail layout used by Elecrig.

## Rails

ER80 uses standard metric **2040 T-slot extrusion**, laid flat:

- 40 mm wide
- 20 mm high
- M5 T-slot hardware
- rail ends tapped M6

## Spacing

Rails are spaced **80 mm center-to-center**.

For example:

| Rails | Center positions | Overall rail depth |
|------:|------------------|-------------------:|
| 2 | 0, 80 mm | 120 mm |
| 3 | 0, 80, 160 mm | 200 mm |
| 4 | 0, 80, 160, 240 mm | 280 mm |

More rails simply continue the same 80 mm spacing.

## Rail ends

Each 2040 rail has two **M6 threaded mounting holes** at each end.

These can be used for side panels and other end-mounted accessories.

See the ER80 drawing for exact positions.

## Compatible parts

An ER80-compatible part should fit any correctly spaced ER80 rail set without depending on a particular board width or side-panel design.

That's it!
