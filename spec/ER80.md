# Elecrig Rail 80 (ER80)

**Status:** Draft / pre-v1.0  
**Specification version:** 0.1-draft  
**SPDX-License-Identifier:** CERN-OHL-2.0-W

## Scope

ER80 defines a mechanical interface for mounting music hardware and accessories
to parallel metric 20-series T-slot extrusion rails.

It does not prescribe the overall shape of a pedalboard, number of tiers, side
supports, device attachment method, or manufacturing process.

## Current draft geometry

The current reference prototype uses:

- metric 20-series T-slot extrusion
- 2040 rails laid flat
- parallel rails
- rail centre-to-centre pitch `P = 80.0 mm`
- M5 fasteners
- M5 T-slot / hammer nuts

The 80 mm pitch is provisional until ER80 v1.0.

## Coordinate system

Recommended convention:

- X: along the extrusion
- Y: front-to-back across rails
- Z: normal to the rail mounting plane
- +Y: toward the rear of the rig
- +Z: upward

## Compatibility

A component may be described as ER80-compatible when it conforms to the
normative geometry of a published ER80 version.

Components should state the version they target and whether they have been
physically tested.

## Versioning

Before v1.0, breaking changes are permitted.

After v1.0:

- patch releases clarify without breaking compatibility
- minor releases add backward-compatible capability
- breaking interface changes require a new major version
