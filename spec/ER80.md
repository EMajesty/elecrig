# Elecrig Rail 80 (ER80)

**Status:** Draft / pre-v1.0  
**Specification version:** 0.1-draft  
**SPDX-License-Identifier:** CERN-OHL-2.0-W

## 1. Scope

ER80 defines a mechanical interface for mounting music hardware and accessories
to parallel metric 20-series T-slot extrusion rails.

It intentionally does not prescribe the overall shape of a pedalboard, number
of tiers, side supports, device attachment method, or manufacturing process.

## 2. Draft reference implementation

The current reference prototype uses:

- 2040 extrusion laid flat;
- parallel rails;
- rail centre-to-centre pitch `P = 80.0 mm`;
- M5 fasteners;
- M5 T-slot / hammer nuts.

**The 80 mm pitch is not stable until ER80 v1.0 is released.**

## 3. Coordinate system

_To be defined from canonical CAD._

Recommended convention:

- X: along the extrusion;
- Y: front-to-back across rails;
- Z: normal to the nominal rail top/mounting plane;
- +Y: toward the rear of the rig;
- +Z: upward.

## 5. Compatibility

A component may be described as ER80-compatible when it conforms to the
normative geometry of a published ER80 specification version.

Components should state the version against which they were designed and
physically tested.

## 6. Versioning

Before v1.0, breaking dimensional changes are permitted.

After v1.0:

- patch releases clarify without changing compatibility;
- minor releases add backward-compatible capabilities;
- breaking interface changes require a new major interface/version.
