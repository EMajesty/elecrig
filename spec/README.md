# Specifications

This directory contains Elecrig's mechanical interface specifications.

The current draft is:

- [`ER80.md`](ER80.md) — Elecrig Rail 80

Specifications define compatibility. Reference builds are examples, not rules.

Before v1.0, breaking dimensional changes are allowed. Once an interface is
stable, compatibility should be preserved wherever possible.

If you want to propose a change to a stable interface, open an issue first and
describe the use case, compatibility impact, and any relevant prototype or CAD.
