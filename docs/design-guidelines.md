# Design guidelines

This document is for rationale and best practices that do not belong in the
normative specification.

## Keep the interface small

Elecrig should standardize only what needs to be shared between independently
designed parts.

For example, ER80 should define how a part attaches to the rail system, not how
a two-tier pedalboard must be constructed.

## Prefer reusable interfaces

A pedal adapter, PSU bracket, cable guide, tier support or case part should all
be able to target the same small set of canonical interfaces.

## Design for remixing

Where practical:

- use common metric fasteners
- make mounting positions adjustable
- keep device geometry separate from rail geometry
- release neutral CAD
- document physically tested fit

## Experimental work

New ideas are welcome without changing the core standard.

Mark them clearly as experimental until the interface is mature enough to be
specified.
