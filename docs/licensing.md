# Licensing

Elecrig uses different licences for different kinds of source.

## Hardware source

The following are licensed under the **CERN Open Hardware Licence Version 2 –
Weakly Reciprocal**, SPDX identifier **`CERN-OHL-2.0-W`**:

- `spec/`
- `cad/`
- `reference-builds/`
- `adapters/`
- `accessories/`

The canonical licence text lives in:

`LICENSES/CERN-OHL-2.0-W.txt`

## Documentation

Content in `docs/` is licensed under **CC BY-SA 4.0**.

## Software

Software in `software/` is licensed under **MIT** unless stated otherwise.

## SPDX identifiers

Where practical, use:

```text
SPDX-License-Identifier: CERN-OHL-2.0-W
SPDX-License-Identifier: CC-BY-SA-4.0
SPDX-License-Identifier: MIT
```

For CAD formats that do not support convenient source comments, put the licence
information in a README in the same directory.

Do not modify the licence texts themselves.
