# Neural DSP Quad Cortex

ER80 mount for the Neural DSP Quad Cortex.

## Compatibility

- Neural DSP Quad Cortex
- ER80
- 3-rail span
- Physically tested

## Hardware

**Device attachment:** Original bottom-cover screws  
**Rubber feet:** Remove

**Additional device hardware:** None

**Rail attachment:**

- 4 × M5×10 bolts
- 4 × M5 hammer nuts
