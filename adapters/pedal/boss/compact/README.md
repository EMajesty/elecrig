# Boss Compact

Elecrig mount for the Boss Compact.

![Mounted device](images/mounted.jpg)

## Compatibility

- **Device:** Boss Compact
- **Interface:** ER80
- **Rail span:** 2
- **Tested:** Yes

## Hardware

**Device attachment:** Original screws
**Rubber feet:** Remove

### Additional device hardware

- None

### Rail hardware

- 4 × M5×10 bolts
- 4 × M5 hammer nuts

## Files

- `cad/` — STEP files
- `print/` — ready-to-print 3MF files
- `images/` — reference and installation photos
