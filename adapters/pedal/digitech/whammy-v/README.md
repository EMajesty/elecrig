# Digitech Whammy V

Elecrig mount for the Digitech Whammy V.

![Mounted device](images/mounted.jpg)

## Compatibility

- **Device:** Digitech Whammy V
- **Interface:** ER80
- **Rail span:** 3
- **Tested:** Yes

## Hardware

**Device attachment:** Original screws
**Rubber feet:** Remove

### Additional device hardware

- None

### Rail hardware

- 4 × M5×10 bolts
- 4 × M5 hammer nuts

- `cad/` — STEP files
- `print/` — ready-to-print 3MF files
- `images/` — reference and installation photos
