# Hammond 125B

Elecrig mount for the Hammond 125B.

- **Device:** Hammond 125B
- **Interface:** ER80
- **Rail span:** 2
- **Tested:** Yes

**Rubber feet:** Depends on the pedal

- 4 × M5 hammer nuts
