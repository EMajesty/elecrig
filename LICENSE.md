# Licensing

This repository contains more than one kind of source material.

## Hardware source

The following are licensed under the **CERN Open Hardware Licence Version 2 –
Weakly Reciprocal**, SPDX identifier **`CERN-OHL-2.0-W`**:

- `spec/`
- `cad/`
- `reference-builds/`
- `adapters/`
- `accessories/`

Use the canonical unmodified licence text in
`LICENSES/CERN-OHL-2.0-W.txt`.

## Documentation

Content in `docs/` is licensed under **Creative Commons
Attribution-ShareAlike 4.0 International (`CC-BY-SA-4.0`)**.

## Software

Software in `software/` is licensed under the **MIT License (`MIT`)** unless a
file or subproject says otherwise.

## SPDX notices

Where the file format allows it, add one of:

```text
SPDX-License-Identifier: CERN-OHL-2.0-W
SPDX-License-Identifier: CC-BY-SA-4.0
SPDX-License-Identifier: MIT
```

CAD formats that do not support convenient source comments should be covered by
a README or licence file in the same directory.

## Important

The licence texts themselves should not be edited. The project-specific
licensing scope belongs in this file and in directory READMEs, not inside the
licence text.
